## Recommended Books for Learning Algorithms and Problem-Solving

### 1. Think Like a Programmer — V. Anton Spraul
This book is the closest match to your problem. It uses C++ and teaches you how to break a problem into smaller steps when you don't know where to start.

### 2. Grokking Algorithms — Aditya Bhargava
This book is beginner-friendly, simple, and full of illustrations. It explains binary search, recursion, hash tables, graphs, and dynamic programming in plain English. The code examples use Python, but they are short and easy to understand if you already know C++.

### 3. Competitive Programmer's Handbook — Antti Laaksonen
This is a free PDF available on the CSES website, and it uses C++. The book is more compact and focuses on competitive programming, so read it after completing the first two books. Practice alongside it using the CSES Problem Set.

### 4. Cracking the Coding Interview — Gayle Laakmann McDowell
This book teaches you how to approach problems the way interviewers expect. It encourages you to start with a brute-force solution and then optimize it. The code examples use Java, but the underlying problem-solving techniques apply to C++ as well.

## Advanced Books (For Later)

Once you have developed a strong foundation in problem-solving and algorithms, move on to these books:

- **Introduction to Algorithms (CLRS):** A comprehensive reference for algorithms and their theoretical foundations.
- **The Algorithm Design Manual — Steven S. Skiena:** Focuses on algorithm design techniques and practical problem-solving.
- **Elements of Programming Interviews in C++:** Covers harder problems and helps you prepare for technical interviews using C++.
